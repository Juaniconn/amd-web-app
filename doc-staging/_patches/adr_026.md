# ADR-026 — Remapeo operativo: Fase 4 es Producción

## Estado

Aceptada

## Fecha

2026-08-13

## Contexto

BUSINESS_SPEC §47 y TECHNICAL_SPEC §40 numeraban:

1. Fundación → 2. CRM → 3. Cotizaciones → **4. Pedidos** → **5. Producción** → 6. Inventario → 7. Compras → 8. Calidad y entregas → 9. Reportes.

Fase 3 ya persistió el pedido mínimo al convertir (ADR-023). La vista operativa `/orders` no existe. Dirección autorizó iniciar **Producción** como siguiente módulo de valor (control de piso) en lugar de construir primero la UI de Pedidos.

## Decisión

La numeración **operativa vigente** (roadmap, procesos, carpeta `docs/Produccion/`) es:

| Fase | Nombre |
|---|---|
| 1 | Fundación |
| 2 | CRM |
| 3 | RFQ |
| 4 | Producción |
| 5 | Inventario |
| 6 | Compras |
| 7 | Calidad |
| 8 | Entregas |
| 9 | Facturación |
| 10 | Dashboard Ejecutivo |
| 11 | Beta Interna |
| 12 | Deploy Cloudflare |

El cuerpo histórico de las specs maestras **no se reescribe** (ADR-021). Este ADR y `docs/roadmap.md` son la fuente del número de fase para agentes.

Pedidos:

- Persistencia mínima: ya existe.
- UI `/orders`, PO del cliente, prioridad y ciclo de estados del pedido: **diferidos**. No son el entregable de Fase 4.
- La OP se ancla al pedido mínimo (ADR-025).

## Alternativas consideradas

- Implementar Fase 4 Pedidos según §47 y luego Producción: rechazado por Dirección; retrasa el control de piso.
- Borrar o renumerar §47 en las specs maestras: rechazado (ADR-021).
- Tratar Producción como «Fase 5» en docs nuevos y «Fase 4» en el prompt del usuario: rechazado; genera contradicción para cualquier IA.

## Razón

Alinea el plan de trabajo con el valor operativo (qué se fabrica) reutilizando el pedido mínimo ya persistido.

## Impacto

- Agentes deben leer [[roadmap]] y este ADR antes de §47 para saber qué fase está activa.
- El sidebar en código sigue diciendo «Fase 5» en `/production` y `/machines` hasta que la implementación lo actualice.
- Inventario pasa a Fase 5 vigente; Compras a Fase 6; Calidad y Entregas se separan (7 y 8).

## Consecuencias

- Documentación de Fase 4 describe Producción, no la vista de Pedidos.
- Changelog / audit / executive summary de implementación se numerarán como `phase-4` = Producción.
