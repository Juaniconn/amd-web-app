# ADR-028 — Rutas de fabricación iniciales y configurables

## Estado

Aceptada

## Fecha

2026-08-13

## Contexto

Una pieza puede recorrer varios centros (BUSINESS_SPEC §16). Sin plantillas, cada OP inventaría la secuencia. Dirección definió tres rutas de arranque y pidió que las futuras las configure el administrador.

## Decisión

Semilla:

- **Ruta A — Pieza maquinada:** RFQ → Ingeniería → CNC → Calidad → Entrega
- **Ruta B — Gabinete metálico:** RFQ → Ingeniería → Láser → Press Brake → Soldadura → Calidad → Entrega
- **Ruta C — Pieza Wire EDM:** RFQ → Ingeniería → CNC → Wire EDM → Calidad → Entrega

Press Brake es el tipo de máquina del centro **Doblado**.

El administrador podrá crear, editar, desactivar y eliminar rutas adicionales. Una OP se instancia con una ruta (o una copia de su secuencia).

RFQ y conversión a pedido siguen ADR-024/023/025. Ingeniería, centros y calidad **no** están implementados.

## Alternativas consideradas

- Una sola ruta genérica «todas las operaciones»: rechazado; no refleja lámina vs maquinado vs EDM.
- Rutas por número de parte desde el día uno: rechazado; no hay maestro de partes.

## Razón

Tres familias reales de AMD México (maquinado, gabinete, EDM) bastan para diseñar el modelo; el resto es configuración.

## Impacto

El modelo de `production_operations` (TECHNICAL_SPEC §10, no creado) debe nacer de la ruta. No hardcodear las tres secuencias en lógica de negocio más allá del seed.
