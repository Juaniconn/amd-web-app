# Resumen ejecutivo — Fase 3 Cotizaciones

**Para:** Dirección General, AMD México  
**Fecha:** 13 de agosto de 2026  
**Estado:** Completada

AMD Operations ya permite capturar una RFQ, cotizar partidas con costo y margen, adjuntar planos y convertir una cotización aprobada en un pedido mínimo.

Ventas opera el módulo. Dirección consulta importes y márgenes. Compras, Producción, Calidad y Almacén no ven cotizaciones.

El pedido generado queda ligado a la cotización. La pantalla completa de pedidos es la Fase 4. Convertir **no** lanza producción.

Los datos DEMO no son cotizaciones reales de AMD.
